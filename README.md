# Deen Islam Platform

The repository is organized into three product applications and one shared backend:

- `app/` — Expo / React Native mobile application
- `web/` — public Deen Islam website
- `admin-panel/` — content and operations dashboard
- `server/` — shared API used by the applications

Run a project from the repository root with `npm run app`, `npm run web`, `npm run admin`, or `npm run server`.
